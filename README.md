# 🤖 AI Chat Backend

A production-ready AI Chat Backend built with:

- TypeScript
- Express.js
- LangChain
- JWT Authentication
- Server-Sent Events (SSE)
- Logging
- Error Handling

## 🚀 Tech Stack

- TypeScript
- Express.js
- Node.js
- Helmet
- Morgan
- CORS
- dotenv

## 📁 Project Structure

```
src/
│── config/
│── controllers/
│── middlewares/
│── routes/
│── services/
│── utils/
│── types/
│── app.ts
└── server.ts
```
